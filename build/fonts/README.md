# Fonts

- **Plus Jakarta Sans** (included, SIL Open Font License 1.1): https://fonts.google.com/specimen/Plus+Jakarta+Sans
- **Butler** by Fabian De Smet (headings, free font, not redistributed here). Save `Butler-Light.ttf` here to match the published PDF.
- **Input Mono** (addresses and times, not redistributed): https://input.djr.com. Save `InputMono-Light.ttf` and `InputMono-Medium.ttf` here, or use JetBrains Mono (`JetBrainsMono-Light.ttf`, `JetBrainsMono-Medium.ttf`, OFL).

Without them the build still runs: Plus Jakarta Sans stands in for headings and the mono face.
